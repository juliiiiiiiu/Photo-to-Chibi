# Repository Working Agreement

## File and directory safety

- If any file or directory needs to be moved, ask the user first and wait for explicit approval before doing it.
- Do not move, rename, delete, relocate, or reorganize any existing file or directory unless the user explicitly authorizes that exact structural change in the current request.
- A question, suggestion, complaint, or discussion about structure is not authorization to change it.
- Before any authorized structural change, state the exact source path, destination path, and affected files, then wait for the user's confirmation before executing it.
- Do not create, replace, or remove symbolic links as a workaround without the same explicit confirmation.
- When a task can be completed by editing file contents in place, preserve all existing paths.
